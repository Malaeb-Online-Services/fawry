# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.1] - 2024-12-19

### Changed
- Updated package namespace to Malaeb\Fawry
- Updated dependencies for Laravel 11/12 compatibility
- Refactored API error message handling
- Updated FawryExpressCheckoutService functionality

### Fixed
- Translation handling and directory structure for Laravel 11
- Email validation removal
- Payment details checking function improvements

## [1.0.0] - 2024-03-19

### Added
- Initial release
- Fawry payment gateway integration
- Support for creating payment links
- Support for checking payment status
- Error handling and validation
- Translation support (English and Arabic)
- Unit tests
- Comprehensive documentation
